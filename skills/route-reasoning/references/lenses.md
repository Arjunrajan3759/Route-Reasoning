# Reasoning lenses

Use these as practical reasoning policies, not claims of complete fidelity to any philosopher.

## Socrates — interrogate assumptions

Best for ambiguity, premature conclusions, requirements discovery, and adversarial review.

1. Define the important terms.
2. Surface assumptions and dependencies.
3. Ask what evidence would falsify the current interpretation.
4. Test a counterexample or boundary case.
5. Conclude only as strongly as the premises allow.

Blind spot: endless questioning. Stop when remaining ambiguity no longer changes the action or answer.

## Aristotle — classify and explain causes

Best for system decomposition, root-cause analysis, taxonomies, and explaining how parts create behavior.

1. Identify the entities and their defining properties.
2. Separate component, behavior, purpose, and context.
3. Trace necessary, enabling, and triggering causes.
4. Relate the specific case to the larger system.
5. Check whether the classification predicts observed behavior.

Blind spot: forcing messy systems into rigid categories. Preserve exceptions and interactions.

## Plato — abstract invariants

Best for reusable models, APIs, design patterns, analogies, mathematical structure, and conceptual simplification.

1. Remove incidental implementation detail.
2. Identify invariants, symmetries, and recurring relationships.
3. Propose the smallest useful abstract model.
4. Map the abstraction back to concrete examples.
5. Reject an abstraction that hides a decisive real-world constraint.

Blind spot: elegant models that do not survive contact with reality. Review with Aristotle or Hume.

## Descartes — decompose and rebuild

Best for calculations, debugging, algorithms, implementation plans, and sequential dependencies.

1. State known inputs, desired outputs, and invariants.
2. Split the task into independent or ordered subproblems.
3. Solve from the simplest stable premise outward.
4. Verify intermediate results and interfaces.
5. Recompose the answer and run an end-to-end check.

Blind spot: locally correct steps built on a false premise. Review with Socrates.

## Hume — ground in evidence

Best for research, experiments, benchmarks, predictions, recommendations, and uncertain causal claims.

1. Separate observations, assumptions, and inferences.
2. Assess source quality, sample relevance, and confounders.
3. Compare the claim with plausible alternatives.
4. Calibrate confidence and identify missing evidence.
5. Prefer a falsifiable next test over unsupported certainty.

Blind spot: refusing useful action under uncertainty. State the best provisional decision and what would change it.

## Kant — enforce rules and conditions

Best for specifications, interfaces, compliance, invariants, formal constraints, and acceptance criteria.

1. Make rules, preconditions, and scope explicit.
2. Check each proposal against every binding constraint.
3. Test consistency across similar cases.
4. Reject exceptions that break a required invariant unless the rule is revised openly.
5. Return a pass/fail result with the violated condition when applicable.

Blind spot: following a bad or incomplete rule. Review the premises with Socrates.

## Hegel — resolve tensions

Best for architecture, policy, strategy, design trade-offs, and apparently incompatible requirements.

1. State both positions in their strongest form.
2. Identify the real contradiction rather than a superficial disagreement.
3. Preserve the valid requirement behind each side.
4. Propose a synthesis, boundary, sequence, or conditional choice.
5. Test whether the synthesis genuinely resolves the conflict or merely renames it.

Blind spot: forced compromise. Some constraints are genuinely incompatible; say so and choose explicitly.
